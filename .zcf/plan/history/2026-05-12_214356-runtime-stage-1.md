# 阶段一：语言运行时基础改造

## 目标

- Node/npm 改用 nvm 管理，移除 NodeSource 安装路径。
- Python 改用 uv 管理，移除 apt/deadsnakes/get-pip/pip/venv 旧路径。
- AI 工具隐式需要 Node/npm 时，默认安装 Node 22 LTS。
- 保持项目无构建链和生成器纯函数模式。

## 执行步骤

1. 更新 `js/data/urls.js` 和 `js/data/defaults.js`，集中维护 nvm/uv URL、版本列表和安装说明。
2. 更新 `js/app.js` 与 `index.html`，移除 `pythonVenv` 状态流和 Python venv 控件。
3. 更新 `js/generators/dockerfile.js`，新增 nvm/uv 生成逻辑并清理旧 NodeSource/deadsnakes/pip/venv 输出。
4. 同步 `build-test/Dockerfile` 参考输出。
5. 运行静态检查，确认输出不包含阶段一禁止的旧安装路径。

## 验收标准

- Dockerfile 输出不包含 `deb.nodesource.com`、`add-apt-repository -y ppa:deadsnakes/ppa`、`get-pip.py`、`python3-venv`、`pip3 config set global.index-url`。
- 显式选择 Node.js 时通过 nvm 安装用户版本。
- 仅 AI 工具需要 Node/npm 时通过 nvm 安装 Node 22。
- 选择 Python 时通过 uv 安装默认 Python 3.12 或用户指定版本。
