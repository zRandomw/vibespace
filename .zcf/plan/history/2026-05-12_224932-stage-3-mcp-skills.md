# 阶段三：MCP / Skills 功能区

> 已过时：本历史计划仍基于旧的 market-style Skills 和 `/root/.agents` 路径。当前实现与正式规格以 `docs/mcp-skills-plan.md` 和 `docs/mcp-skills-import-design.md` 为准。

## 目标

- 在 AI 工具步骤中，为 Codex 提供 MCP / Skills 选择能力。
- 支持默认源、自定义源、源 JSON 导入导出、实时抓取失败降级、手动条目 JSON 导入。
- 将已选 MCP / Skills 接入 Codex Dockerfile 生成逻辑。

## 执行步骤

1. 同步阶段二必要基线：Codex CLI、Codex AGENTS.md 输出、移除 ZCF 工作流入口。
2. 新增默认源数据文件，保存市场源和内置示例条目。
3. 扩展 Alpine 状态：源管理、条目刷新、导入导出、选择列表。
4. 扩展 Codex 配置 UI：MCP / Skills 标签页、源列表、条目列表、导入导出和已选列表。
5. 扩展 Dockerfile 生成器：生成 `/root/.codex/config.toml` 和 `/root/.agents/skills` 安装说明。
6. 验证静态语法、页面脚本加载和生成输出关键内容。

## 验收标准

- 原 ZCF 预设工作流区块不再出现。
- Codex 选中后显示 MCP / Skills 配置区。
- 默认源和内置条目可见，源配置可导入导出。
- 非法 JSON 不覆盖当前配置并显示错误。
- 抓取失败不阻塞生成，可打开市场或手动导入 JSON。
- 已选 MCP / Skills 进入 Codex 生成逻辑。
- 未选择 Codex 时不生成 Codex MCP / Skills 配置。
